# Legacy oracle

`AI.js` and `GameNode.js` are unmodified copies of the Beta 0.8 sources
(`client/src/` on `master`); `definitions.js` is the relevant excerpt of
`client/src/definitions.js`. They are loaded in a sandbox by `../legacy.ts`
and used by the tests to prove that the TypeScript rules engine and AI
players behave exactly like the originals. Do not edit them.
